# Как контрибьютить

Спасибо за интерес к проекту!

## Порядок работы

1. Форкните репозиторий и создайте ветку от `main`:
   `git checkout -b feature/короткое-описание`
2. Внесите изменения, придерживаясь стиля кода проекта (см. `.editorconfig`).
3. Коммиты — по [Conventional Commits](https://www.conventionalcommits.org/ru/):
   `feat: ...`, `fix: ...`, `docs: ...`, `chore: ...`
4. Откройте Pull Request, заполнив шаблон.

## Требования к PR

- Один PR — одна логическая задача.
- Обновлённые тесты и документация, если менялось поведение.
- Пункт в `CHANGELOG.md` (раздел `Unreleased`).
