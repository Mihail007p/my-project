# Нитро-Шоссе — аркадный прототип шоссе

Браузерная аркадная гонка в духе «шоссейных» режимов Asphalt: псевдо-3D дорога,
закатное небо, трафик, отбойники, нитро и счёт обгонов.

**Один файл** — `index.html`. Ни библиотек, ни картинок, ни сборки: вся графика
рисуется процедурно на Canvas 2D.

## Как запустить

```bash
# вариант 1: просто открыть файл
xdg-open index.html      # или двойной клик

# вариант 2: локальный сервер (нужен для тач-устройств в одной сети)
python3 -m http.server 8000
# → http://localhost:8000
```

## Управление

| Клавиша | Действие |
|---|---|
| `←` `→` или `A` `D` | руль |
| `↑` / `W` | газ (по умолчанию машина разгоняется сама) |
| `↓` / `S` | тормоз |
| `SHIFT` или `SPACE` | нитро |
| `P` / `Esc` | пауза |
| `M` | звук вкл/выкл |

На тач-устройствах кнопки появляются автоматически.

## Механики

- **Дистанция и обгоны** — основные метрики заезда, рекорд хранится в `localStorage`.
- **Нитро** — расходуется при бусте, медленно восстанавливается, пополняется
  баллонами на дороге (+34) и за проезд «вплотную» к машине (+5).
- **Урон** — растёт от ударов о трафик (зависит от скорости) и от скрежета о парапет.
  При 100 — авария и экран перезапуска.
- **Трафик** — 12 машин, живут по всей длине трассы (не только в кадре), перестраиваются
  по четырём полосам, притормаживают перед теми, кто впереди, и перерождаются
  далеко позади → впереди, чтобы не появляться из воздуха.
- **Трасса** — 1865 сегментов, замкнутая петля: спуски/подъёмы, повороты разной крутизны,
  фиксированный сид, так что асфальт всегда одинаковый.

## Как это устроено

Классический псевдо-3D рендер: трасса — массив сегментов, каждый проецируется
в экранные координаты (`project()`), рисуется от дальнего к ближнему с отсечением
по `clip` и туманом `expFog`. Объекты (машины, баллоны, фонари) «крепятся» к сегментам
и рисуются в порядке отрисовки сегментов, что автоматически даёт корректные перекрытия.

Основные блоки в `index.html`:

| Блок | Что делает |
|---|---|
| `buildTrack()` | процедурная генерация петли трассы |
| `project()` / `renderRoad()` | проекция и отрисовка асфальта, разметки, парапетов |
| `renderSprites()` | машины, баллоны, фонари с туманом и отсечением |
| `updatePlayer()` | разгон, нитро, снос на поворотах, урон |
| `updateTraffic()` | ИИ трафика, столкновения, обгоны |
| `drawCarRear()` | процедурная отрисовка машин (игрок и трафик) |
| `frame()` | фиксированный шаг физики + адаптивное качество |

## Тесты

```bash
node tests/headless-test.js      # загрузка и 60 секунд симуляции без DOM
node tests/scenario-test.js      # 23 проверки: удары, обгоны, барьер, трафик, нитро, авария
node tests/screenshot-test.js    # реальный прогон в headless Chrome + скриншоты
```

Для `screenshot-test.js` нужен puppeteer: `npm i puppeteer` (в самом репозитории
зависимостей нет, тест подхватывает пакет извне).
