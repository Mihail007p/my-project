# Постоянная ссылка на игру

## Правило для ИИ-агентов

Ссылку с названием ветки (`arena/...`) нельзя выдавать как постоянную: ветка
может получить новые коммиты, быть переименована или удалена.

Для готовой версии игры всегда используй полный SHA коммита:

```text
https://raw.githack.com/Mihail007p/my-project/<FULL_COMMIT_SHA>/new-project/play.html
```

Перед ответом пользователю выполни:

```bash
git rev-parse HEAD
```

Подставь полученный полный SHA вместо `<FULL_COMMIT_SHA>`. После нового коммита
постоянная ссылка будет указывать на прежнюю неизменяемую версию, а для новой
сборки нужно выдать новый SHA-адрес.

Ссылки с веткой можно давать только как временный preview. Не подменяй ими
permalink, не полагайся на `?v=` как на гарантию постоянства и не меняй чужую
ветку `arena/01a09448-my-project` из сессии, закреплённой за
`arena/01a0987d-my-project`.
