# Мир игры: городское шоссе

Текущая версия игры — **WebGL-мир целиком**, без геймплея: задача этапа —
детализированно проработать окружение. Машина игрока и физика — следующий этап.

## Что уже в мире

| Элемент | Детали |
| --- | --- |
| Трасса | замкнутое кольцо R≈1150 м, длина ≈ **8.83 км**, 16.8 м асфальта, обочины, гравийная кромка, откос |
| Осевое | бетонный отбойник (jersey) по всей длине |
| По краям | металлические ограждения с стойками каждые 12 м |
| Фонари | каждые 45 м с двух сторон: 9.4 м столб, кронштейн 3 м, светящийся плафон + световое пятно |
| Тоннель | 360 м на 21 % длины кольца: арочный профиль 19.6 × 9.5 м, потолочные светильники каждые 14 м, порталы, сверху — платформа 70 м шириной, на которой стоит город |
| Эстакады | 4 путепровода над дорогой: пролёт 15 × 96 м, парапеты, 4 опоры до земли, освещение |
| Знаки | фермы над дорогой каждые ~760 м с зелёными щитами, билборды на опорах |
| Город | ~3 600 зданий: «первая линия» вдоль трассы (отступ от оси ≥ 45 м) + квартальная сетка 130/22 м до R=2400, подиумы, уступы башен, парапеты, вентиляция, антенны, светящиеся окна ночью |
| Улицы города | асфальт улиц, тротуарные рамки кварталов, дворы, парки с деревьями, разнотон кварталов |
| Обочины | ~950 деревьев вдоль трассы, шумозащитные экраны участками на 28.5 м от оси |
| Силуэт | 420 дальних коробок на R 2500–3500 м |
| Небо | пресеты день / закат / ночь, солнце с ореолом, объёмные облака на fbm, звёзды, туман с плотностью от времени суток |
| Свет | ламберт + блики, самосветящиеся окна и лампы ночью, аддитивный проход свечения (мягкие круглые пятна света) |

Геометрия — **один статический меш** (~363 тыс. треугольников, 1.09 млн вершин) плюс
второй меш аддитивного свечения; отрисовка — **3 вызова** на кадр (небо, мир, свечение).
Разметка дороги считается прямо в шейдере по UV в метрах.

## Управление

* `1` `2` `3` — камера: езда по трассе / свободный полёт / облёт
* `W A S D` — движение, `Shift` — ускорение, `Space` — тормоз/вверх, `R`/`C` — вверх/вниз
* мышь (зажата) — обзор, колесо — скорость полёта или радиус облёта
* `[` `]` — время суток, `F` — туман, `L` — свечение, `H` — панели, `P` — статистика генерации

## Как это проверяется

```bash
python3 tools/build.py          # собрать index.html из src/
node tools/world-stats.js       # счётчики геометрии по этапам, без браузера
node tests/world-test.js        # puppeteer: 9 снимков в docs/screenshots/world/
```

Снимки складываются в `docs/screenshots/world/`: аэросъёмка заката, езда днём и на закате,
ночь, подъезд к тоннелю и тоннель изнутри, путепровод, город с высоты, облёт.

**Важно для headless:** браузер надо запускать с `--use-angle=swiftshader`
(`--use-gl=swiftshader` теряет WebGL-контекст, и кадр выходит пустым — уже проверено).

Снимки делаются через `window.__world.step(n, dt)` — синхронный шаг кадров, поэтому
они детерминированы и не зависят от троттлинга requestAnimationFrame в headless.

## Отладочный доступ из консоли

```js
__world.info()              // здания, треугольники, время генерации, fps, камера
__world.setMode('drive')    // 'drive' | 'fly' | 'orbit'
__world.setTime(0.5)        // 0 день … 1 ночь
__world.teleport(3600, -4.6)// километры по трассе и смещение от оси
__world.keys.KeyW = true    // эмуляция клавиш
__world.step(4, 1/30)       // прокрутить кадры синхронно
```

## Структура исходников (`src/`, склейка в `index.html`)

| Файл | Содержимое |
| --- | --- |
| `index.head.html` | оболочка: canvas, HUD, панели, стили |
| `00-math.js` | векторы, матрицы, шум, ГПСЧ |
| `01-shaders.js` | шейдеры неба и мира (коды материалов 0…9) |
| `02-mesh.js` | построение меша: боксы, цилиндры, сферы, профили вдоль трассы |
| `03-path.js` | замкнутая трасса: сэмплы, поиск ближайшей точки, рельеф |
| `04-world.js` | сборка мира: дорога, тоннель, эстакады, знаки, город, силуэт |
| `05-render.js` | WebGL-рендерер, пресеты времени суток, кадр |
| `06-app.js` | камеры, ввод, генерация по этапам, цикл, HUD |
