## Сессия 0 — ветка `arena/01a09448-my-project`, коммит `382d8bd` (до текущей серии)

**Задача пользователя:** «изучи и исправь машину» — в заезде ехала запасная
процедурная машина вместо Ferrari.

**Что сделано:** первая попытка починить загрузку модели: блокировка кнопки
«ПОЕХАЛИ» до загрузки, возврат к Draco-модели.

**Почему этого оказалось мало (унаследованные грабли):**
- `play.html` остался НЕ самодостаточным: GLTFLoader/модель тянулись внешними
  файлами, а по ссылке raw.githack внешних файлов нет → модель не грузилась
  никогда, игрок всегда ехал на «кирпиче»;
- тяжёлая `ferrari-plain.glb` (8.2 МБ) вместо Draco (1.7 МБ): DRACOLoader лежал
  в `assets/` неиспользованный, декодер не был подключён;
- старт не ждал модель: гонка начиналась раньше, чем модель доезжала.

Эта ветка больше не обновляется: текущая серия сессий закреплена за
`arena/01a095ab-my-project` (см. Сессию 2 про ссылки githack).

   (`modelFailed`) с запасной машиной и понятной подписью.
3. `modelApplied()` пересобирает машины в меню (`setupRace()`), чтобы настоящая
   модель была видна ещё до старта.
4. Починен `tools/build-offline.py`: раньше падал на `assert` и молча оставлял
   битый файл; теперь каждая подстановка обязательна, готовый `play.html`
   проверяется на внешние ссылки. Итог: самодостаточные 4.09 МБ (three.js +
   GLTFLoader + DRACOLoader + декодер + GLB внутри).
5. Добавлен `tools/sync-docs.py` — зеркало гонки в `docs/` (GitHub Pages) с
   проверкой ссылок.

   и воркеров, запасная машина при ошибке.

8. Попытка обновить `.github/workflows/ci.yml` ОТКЛОНЕНА GitHub App (нет права

   для ручного копирования.

**Грабли, зафиксированные здесь впервые:**
- push с изменением `.github/workflows/*` отклоняется — не включать в коммиты;
- Draco-декодер в офлайн-режиме (`file://`/без воркеров) должен эмулировать

   `window.print`;

- `raw.githack.com` и `raw.githubusercontent.com` из песочницы не открываются

   пользователем.

**Результат:** тесты зелёные, коммит `f177500` запушен.

## Сессия 3 — коммит `8675fb9` (2026-09-13)

**Задача пользователя (со скриншотом):** «вот прогресс, но у меня на модели
Tecno Pova neo 3 лагает». На скриншоте Ferrari уже настоящая — значит модель
доехала; лаги = производительность.

**Диагноз:** кадр собирал ~2.2 млн треуг. (6 машин × 359 тыс.) + тени +
DPR 1.5; Mali-G52 такое не тянет.

**Действия:**
1. `TOUCH`/`PERF` на старте скрипта: на touch-устройствах `antialias:false`,
   `DPR_CAP=1.0`, карта теней 1024 и `PCFShadowMap` вместо PCFSoft.
2. `PERF.lightAI`: соперники на лёгких процедурных мешах `buildCarMesh`
   (~2 тыс. треуг.), машина игрока — настоящая GLTF. На десктопе всё полное.
3. Губернер `perfTick(dt)` в `tick()`: замер FPS раз в секунду только в
   заезде; <40 FPS две секунды — ступень вниз (lvl1: DPR ×0.75; lvl2: ×0.6 и
   тени off с пересборкой материалов); стабильно >55 FPS пять секунд — ступень
   вверх. `applyPerf()`/`setDPR()`.
4. Хук `__game.perfInfo()` + `__game._perfTick` для тестов.
5. Сценарий 5 в `car-model-test.js`: эмуляция touch через
   `navigator.maxTouchPoints`, проверки лёгких соперников, настоящей машины
   игрока, DPR ≤ 1.0, просадки/восстановления губернера → 94 проверки.

**Грабли:**
- `const DPR_CAP` внутри `try{}` не виден функциям снаружи
  (ReferenceError в `setDPR`) — константы уровня скрипта держать вне `try`;
- в сценарии 5 губернатор дергается через `_perfTick(1/30)` пачками по ~2 с:
  одна выборка = 1 с накапливаемого времени.

**Результат:** 94/94 зелёные; коммит `8675fb9` запушен; пользователю выдана
ссылка с `?v=3`.

**Задача пользователя:** «Сделай машины соперников другие машины, спрайс,

**Действия:**
1. Сгенерированы пять визуально разных машин — Falcon (синий суперкар), Vortex
   (жёлтый electric hypercar), Baron (зелёный muscle coupe), Ghost (фиолетовый

   ракурсах на magenta chroma-key.

   фильтры PNG, magenta → alpha, crop, единый масштаб и RGBA-атлас 1280×512.
   Готовый результат — `new-project/assets/opponents/opponent-sprites.png`,
   индексы — `sprite-data.js`.
3. `Car` использует дешёвый `THREE.Sprite` для каждого AI после загрузки
   атласа. Перед/задний ряд выбирается по положению камеры; на время загрузки
   остаётся процедурный fallback. Игрок не менялся и едет на GLTF Ferrari.
4. Обновлены `build-offline.py` и `sync-docs.py`: атлас встраивается в
   `play.html` data-URI и копируется в `docs/`. Отдельно исправлено затенение
   глобального Node `process`: генератор использует `processSprite`, а не
   одноимённую функцию.

   загрузчик текстуры должен тихо оставить fallback; в настоящем браузере

**Результат:** `make car` — 94/94; `make play` — самодостаточный `play.html`
4.90 МБ; `make docs` — 9 файлов, битых ссылок нет. Изображение атласа
