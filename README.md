# Нитро-Шоссе → Городское шоссе (WebGL)

Игра переписывается с нуля: вместо 2D-аркады — настоящий трёхмерный мир (WebGL).
Сейчас готов **мир**: городское шоссе длиной 8.8 км с тоннелем, путепроводами,
знаками, фонарями, шумозащитными экранами и городом вокруг — ~3 600 зданий.

* Играть: `index.html` (открыть в браузере) или `make serve` → http://localhost:8000
* Подробности мира, управление и проверки: [`docs/WORLD.md`](docs/WORLD.md)
* Журнал работ ИИ-агентов: [`docs/AI-JOURNAL.md`](docs/AI-JOURNAL.md);
  инструкция для будущих агентов: [`docs/AI-HANDBOOK.md`](docs/AI-HANDBOOK.md)
* Предыдущая версия игры (2D-аркада) — в истории коммитов, коммит `b32889b`.

В репозитории живут две независимые игры — мир и гонка:

| Что | Где | Запуск |
|---|---|---|
| Мир «Городское шоссе» (WebGL, без геймплея) | `index.html` (собирается из `src/`) | `make serve` → http://localhost:8000 |
| Гонка **STREET APEX** (3D, 6 машин, 3 круга) | `new-project/index.html` | `make serve` → http://localhost:8000/new-project/ |
| Гонка одним файлом (без сети и сервера) | `new-project/play.html` | двойной клик по файлу |

## Гонка STREET APEX (`new-project/`)

Трёхмерная аркадная гонка на three.js: замкнутая трасса 2.5 км, 3 полосы,
5 соперников с ИИ, 3 круга, дрифт, отбойники, позиции и таблица результатов.
У каждого соперника своя современная 3D-машина: Falcon, Vortex, Baron, Ghost или
Titan с разными пропорциями и обвесом. Машина игрока — настоящая 3D-модель
Ferrari 458 (`assets/ferrari.glb`, Draco, 1.7 МБ), цвет кузова выбирается в меню.
AI-рендеры и прозрачные атласы сохранены в `assets/opponents/` как арт-референсы. В частности, `opponent-animated-sprites.png` содержит 5 строк машин и по 4 кадра руления.

Модель грузится **до** старта: пока она не приехала, кнопка «ПОЕХАЛИ»
заблокирована и показывает прогресс. Если загрузка не удалась — через 20 секунд
старт открывается с запасным (процедурным) автомобилем, игрок в меню не заперт.

```bash
make serve    # гонка: http://localhost:8000/new-project/
make play     # пересобрать new-project/play.html — один самодостаточный файл (~4 МБ)
make docs     # зеркалить гонку в docs/ (GitHub Pages)
make car      # тест машины: модель, блокировка старта, офлайн-режим (Node)
make racing   # смоук-тест гонки: трасса, ИИ, физика, отбойник (Node)
```

Для публикации пользователю постоянной считается только ссылка с полным SHA
коммита, а не ссылка с именем ветки. Правило для ИИ-агентов: [`docs/PERMANENT-LINK.md`](docs/PERMANENT-LINK.md).

Управление: `W A S D` / стрелки — руль и газ, `Пробел` — дрифт, `C` — камера,
`R` — вернуть на трассу, `M` — звук, `Esc` — пауза. На телефоне — сенсорные кнопки.

## Что внутри

Историческая 2D-версия игры (в рабочем дереве её заменил WebGL-мир, код — в
истории, коммит `b32889b`); [`GAME.md`](GAME.md) и [`docs/ROADMAP.md`](docs/ROADMAP.md)
описывают именно её.

**Нитро-Шоссе** — браузерная аркадная гонка в духе шоссейных режимов Asphalt:
псевдо-3D дорога, закат, трафик, отбойники, трамплины, дрифт и гонка
на 3 круга с четырьмя соперниками. Один файл `index.html`, без библиотек
и сборки — вся графика процедурная.

Открыть: `index.html` или `python3 -m http.server 8000` → http://localhost:8000

Управление: `←` `→` руль, `SHIFT` нитро, `X` дрифт, `P` пауза, `M` звук.
Подробности — в [GAME.md](GAME.md).

![Гонка на закате](docs/screenshots/3-road.png)

## Возможности

- Псевдо-3D шоссе с поворотами, спусками, подъёмами и трамплинами
- Гонка: 3 круга, 4 соперника, позиции, отсчёт старта, лучший результат
- Трафик с ИИ: перестроения, торможение, столкновения
- Дрифт: занос, следы шин, дым, очки и бонус нитро
- Полёты с трамплина: в воздухе руль и барьеры не действуют
- Нитро: баллоны на дороге, бонус за проезд «вплотную», награда за дрифт
- Урон, авария, экраны финиша и перезапуска
- Закатный фон: горы, город с окнами, фонари
- Адаптивное качество и тач-управление

## Разработка

```bash
make serve     # игра на http://localhost:8000
make test      # все автотесты (без браузера)
make play      # самодостаточный new-project/play.html
make docs      # зеркало гонки в docs/ для GitHub Pages
make shots     # скриншоты мира в headless Chrome (нужен puppeteer)
make help      # список команд
```

Тесты по отдельности (все — Node, браузер не нужен):

```bash
node tools/world-stats.js          # счётчики геометрии мира
node tools/racing-smoke-test.js    # гонка: трасса, ИИ, физика, отбойник
node tools/car-model-test.js       # машина: Draco-модель, старт, офлайн-сборка
node tests/world-test.js           # снимки мира (только если есть puppeteer)
```
